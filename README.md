# PlanCraft

[Open PlanCraft](https://fionviber.github.io/PlanCraft/)

Create and edit floor plans, arrange furniture, and export images or plan JSON files.

The 2D editor, 3D preview and all required components are bundled into one HTML file. No CDN or external resource requests are needed.

Open the link to start. No account or password is required. Network resource loading is disabled by the page's Content Security Policy.

## Run locally

Download `index.html` and open it in your browser.

The 3D components use Three.js 0.160.0; its licence notice is retained in the bundled code.
