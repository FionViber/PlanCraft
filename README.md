# PlanCraft

[Open PlanCraft](https://fionviber.github.io/PlanCraft/)

Create and edit floor plans, arrange furniture, and export images or plan JSON files.

The 3D preview loads Three.js from jsDelivr and requires an internet connection.

Open the link to start. No account or password is required. The supplied page is published unchanged as `index.html`.

## Run locally

Download `index.html` and open it in your browser.
